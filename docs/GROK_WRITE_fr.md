# Grok 회화 작성 규칙 — 프랑스어 (방 첫 메시지에 한 번만 첨부, 이후 메시지는 파일 이름 한 줄 + 그 파일 첨부)

이 방에서는 앞으로 **회화 파일 이름 한 줄**만 보내고 그 파일(JSON)을 첨부한다. 첨부 파일에는 **대사가 없다** — 제목·장면(`scene`)·인물(`speakers`·`cast`)·반전 턴(`twist`)·문법 목표(`goal`)·넣을 표현(`expressions`)·턴마다 화자와 감정 힌트만 있다. 이것으로 **모든 줄을 처음부터** 쓴다. 턴 수와 화자 순서는 그대로 지킨다. 편마다 톤·인물·형식은 이전 답과 똑같이 맞춘다.

## 쓰는 법
- **일상 안에서 터지게**: 가게·식당·길·집·학교·직장·약속·전화처럼 학습자가 실제로 겪는 장면과 그 자리의 흔한 표현이 바탕. 반전·러브·플러팅은 줄이지 말고 다 넣되 그 일상 속에서(말실수·착각·깜빡함·예상 밖 대답·설렘). 우연의 일치·과장된 소동·판타지 금지.
- 지금 파리 20대가 그 장면에서 실제로 하는 프랑스어 구어로. 교과서체·번역투·설명 대사 금지. ne 빠짐, ouais, t'as, y a, chais pas 환영.
- `twist` 턴 근처에서 터지게, 웃음 킥 1개, 연애 편은 심쿵 한 줄(여성이 먼저 다가가게).
- `goal` 의 문법이 실제 문장에 나와야 한다. `expressions` 중 2개 이상을 그 모양 그대로 넣는다.
- `{name}` 은 학습자 A 의 이름 자리 — 그대로 둔다. 학습자 A 는 국적을 정하지 않는다. 숫자는 글자로(dix). 실존 인물·작품·브랜드 금지, 12+.
- 고정 인물(성격 유지): Léa·Camille(여), Hugo·Théo(남). 그 밖의 인물은 `cast` 성별대로.
- 말투: 친구·연인 = tu(한국어 반말), 직원·낯선 사람·상사 = vous(한국어 존댓말).

## 레벨(파일의 `region`)별
| 레벨 | 한 턴 단어 | 지킬 것 |
|---|---|---|
| R0 | 2~9 | 짧은 인사·맞장구. tu·단수만 |
| R1 | 2~9 | tu·단수·on 만(nous·vous 활용 금지). 현재·복합과거·aller+원형·je voudrais. y·en 은 on y va·il y a·j'en ai marre 같은 덩어리만 |
| R2 | 1~14 (채팅 편은 문자 메시지처럼) | R1 과 같되 qui·que 관계절 가능 |
| R3 | 1~12 | 복수·vous·nous 가능, 존댓말 장면에서 ne…pas 살림. 접속법은 il faut que 덩어리만 |
| R4 | 1~18 | 접속법·조건법·si 가정·대명사 결합·반과거 vs 복합과거 — `goal` 대로 |
| R5 | 1~18 | 새 문법 없이 생활 어휘를 풍부하게 |

## 답 형식(이것만, 코드 블록 하나)
줄마다 `번호 화자: 프랑스어 / 한글 독음 / 한국어 / 뜻 풀이 / 감정`
- 화자는 첨부 파일의 글자(A·B·C…) 그대로.
- 한글 독음 = 실제 소리대로(연음·연결·묵음 반영). j/je = 쥬, u = 위, -in/-ain = 앵, -an/-en = 앙, -on = 옹, r = ㄹ, 무기음은 된소리 ㄲ·ㄸ·ㅃ·ㅆ. 예: Tu viens d'où ? → 뛰 비앵 두?
- 뜻 풀이 = 학습자에게 보이는 짧은 낱말 풀이(`gratuit = 무료 · ça te dit ? = 할래?`). 작업 표시(새로 씀·필수·punchline·callback·킥 등)는 쓰지 않는다.
- 감정 = 음성용 16개 중 하나: neutral polite stiff cheerful amused teasing excited surprised shout tsukkomi annoyed sad worried flustered shy gentle. 한 턴 안에서 바뀌면 `surprised:Quoi ?|gentle:Viens.`(이어 붙이면 프랑스어 본문과 같게). neutral 만 쓰지 말 것.
- **학습자 A 의 문장이 여성일 때 달라지면**(je suis content → contente, je suis allé → allée) 그 줄 끝에 ` / 여: 여성형 프랑스어 = 여성형 독음` 을 붙인다. 안 달라지면 붙이지 않는다.
- 채팅 편(`kind: chat`)은 턴의 `at` 시각을 바꾸지 않는다(답에 쓰지 않아도 됨).

# 프랑스어앱 고정 캐릭터 (2026-11-03 사용자 통과)

기준 그림: `../art/chars_fr_v1.jpg` (Grok, 점토 톤, 요청문 `../art/req_chars_fr.md`).
장면 그림을 Grok 에 요청할 때는 **이 시트를 항상 첨부**하고 아래 특징을 그대로 붙인다.

- **화풍**: 펠트·점토 인형 질감, 둥근 얼굴, 따뜻한 조명, 연한 크림·파스텔 배경. 그림 안에 말풍선·글자 없음(앱이 얹음). 실존 인물을 닮게 하지 않는다.
- **Camille(카미유)** — 20대 초 여성, 재치·직설, 카페 일, 영화 좋아함. 밤색 웨이브 단발·일자 앞머리, 남색·흰 줄무늬 티 + 카멜 트렌치 + 검은 슬림 팬츠, 캔버스 토트백, 한쪽 입꼬리만 올린 웃음.
- **Léa(레아)** — 20대 초 여성, 미대생, 몽상가, 먼저 설레고 먼저 들킴. 적갈색 곱슬머리를 느슨하게 올려 묶음, 머스터드 니트 + 데님 롱스커트 + 갈색 앵클부츠, 스케치북.
- **Hugo(위고)** — 20대 중반 남성, 느긋한 요리사 지망생, 농담 많음. 짙은 곱슬머리·짧은 수염, 회색 티 + 데님 재킷 + 검은 진, 흰 스니커즈, 바게트 종이봉투.
- **Théo(테오)** — 20대 중반 남성, 솔직·직진, 셰어하우스 룸메이트, 자전거. 여섯 중 가장 큼, 밝은 갈색 사이드 헤어, 네이비 피코트 + 흰 셔츠 + 베이지 치노, 자전거 헬멧.
- **학습자(남)** — 국적 중립, 짧은 곱슬 흑발, 프렌치 블루(#3F5FD6) 후드티 + 베이지 팬츠(밑단 접음) + 흰 운동화, 갈색 백팩(한쪽 어깨). 이름은 학습자가 프로필에서 정한다(`{name}`).
- **학습자(여)** — 국적 중립, 검은 단발 보브, 남색(#0A2540) 자켓 안에 프렌치 블루 티 + 베이지 팬츠 + 갈색 부츠, 갈색 백팩.
- 색은 앱 강조색 프렌치 블루 #3450B8·크림·파스텔과 어울리게. 프랑스 느낌 소품(줄무늬·바게트·자전거)은 인물당 하나 이하.

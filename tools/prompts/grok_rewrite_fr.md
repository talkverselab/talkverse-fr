# Grok 재작성 규칙 — 프랑스어앱 회화 (이 파일은 방 첫 메시지에 한 번만 첨부)

이 방에서는 앞으로 **파일 이름 한 줄**만 보냅니다. 첨부된 JSON 은 한국인 학습자용 프랑스어 회화 초안 1편입니다. 아래 규칙대로 다시 써서 **같은 모양의 JSON 하나만** 코드 블록으로 답하세요(설명 없이).

1. 프랑스 사람이 지금 실제로 하는 구어로. 교과서체·번역투 금지(ne 빠짐, ouais, t'as, y a 허용).
2. 일상이 중심 — 가게·식당·길·집·학교·직장·약속·전화의 흔한 표현. 반전·설렘·플러팅은 그 일상 안에서 있을 법한 의외성(말실수·착각·깜빡함·예상 밖 대답)으로. 우연의 일치·과장된 소동·판타지 금지.
3. 유지: 턴 수, 화자, `twist` 턴 번호와 `twist_type`, `goal` 의 문법(이 문법이 실제 문장에 나와야 함), `expressions` 2개 이상이 실제 문장에, tu/vous 구분, 턴당 단어 수(R0·R1 2~9, R2 1~14, R3 1~12, R4·R5 1~18).
4. 턴마다 `emotion`(한 감정) 또는 `segs`([[감정, 문장 조각], …] 이어 붙이면 fr 과 같음). 감정 값: neutral polite stiff cheerful amused teasing excited surprised shout tsukkomi annoyed sad worried flustered shy gentle.
5. `fr` 을 바꾸면 `ko`(자연스러운 한국어, tu=반말·vous=존댓말)와 `rd`(한글 독음: 실제 소리, 연음·묵음 반영, r=ㄹ, j/je=쥬, u=위, -in=앵, -an/-en=앙, -on=옹, 된소리 ㄲㄸㅃㅆ)도 맞춰 고친다. A 의 성별로 바뀌는 문장은 fr 남성형 + `fr_f`·`rd_f` 여성형.
6. 출처·작품명·실존 인물 금지. 수위 12+.
7. `note`(뜻 풀이)·`tags`·`new` 는 바뀐 문장에 맞게 고친다. 다른 칸은 그대로.

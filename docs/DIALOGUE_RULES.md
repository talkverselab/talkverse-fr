# 회화 원칙 — 프랑스어앱

**공통 원칙(SSOT): https://talkverse.uk/talkverse/dialogue-rules/** (2026-11-02 확정) · 절벽 기준표: https://talkverse.uk/cliff/18/
레벨·턴 수·독음·설명 언어·반전·수위·변이 파일·검수 방법은 전부 위 문서를 따른다. 이 파일에는 프랑스어 특이점만 적는다.

## 프랑스어 특이점

- **기본 변이**: 표준 프랑스어(프랑스, `fr_FR`). 캐나다(퀘벡)·벨기에 등은 쓰지 않거나, 쓰게 되면 공통 원칙대로 별도 파일.
- **한글 독음**: 실제 소리대로 적는다 — 연음(liaison)·연결(enchaînement)·묵음 반영. 예: `Je m'appelle` 쥬 마뻴, `Tu viens d'où ?` 뛰 비앵 두?, `Je viens de Corée` 쥬 비앵 드 꼬레, `C'est ouvert` 쎄 우베르.
  - 표기 기준(초안 데이터에서 쓰던 것): j/je = 쥬, u = 위·뛰, 비음 -in/-ain = 앵, -an/-en = 앙(항), -on = 옹, r 은 문맥에 따라 ㅎ/ㄹ(프랑쎄·프항쎄 혼용 → 정리 필요), 된소리 ㄲ·ㄸ·ㅃ·ㅆ 로 무기음 표시.
  - ⚠ r 소리 표기(ㅎ/ㄹ)가 초안에서 섞여 있다 — 새로 만들 때 하나로 정하고 자동 검사에 넣을 것.
- **턴 길이**: 구어 기준 짧게. R1 은 3~8단어, 위로 갈수록 종속절·대명사 결합(y·en·le·lui) 허용.
- **말투**: 친구 사이 `tu`(번역은 반말), 처음 보는 사람·가게·공공장소 `vous`(번역은 존댓말). 한 편 안에서 tu→vous 전환이 생기면 반전 장면으로 쓸 수 있다.
- **성별판 규칙**: 화자 성별에 따라 형용사·과거분사 일치가 바뀐다(`je suis content/contente`, `je suis allé/allée`). 화자 성별을 인물 설정에 고정하고, 성별판을 만들면 일치 형태만 바꾼다. 상대를 가리키는 말(`tu es prêt/prête`)도 상대 성별에 맞춘다.
- **콘텐츠 원본**: `~/talkverse/_update_kit/content/fr.py` → `build_content.py` 로 앱 자산 생성(지금 초안은 옛 L1 5편 × 8턴 — 공통 원칙의 R1~R4 로 다시 짜야 함).

## 굴절어 회화 전략 적용(2026-11-08, `~/talkverse/INFLECTED_LANG_STRATEGY.md` 사용자 결정 11항목)

### 이미 쓴 4편 점검(고치는 건 사용자 지시 뒤)
- `R1/love/r1_love_c1`(레벨 1): tu·단수 ✓. 어휘가 코어 40 기준이 아니다(코어가 아직 없음).
- `R2/life/r2_life_b1`(레벨 2 챗 실전): 채팅 편이 아니고, 이웃 조연이 vous(A4 위반).
- `R3/friends/r3_friends_b1`(레벨 3 그래머2): 복수·vous(친구 여럿) ✓, 그러나 새 단어가 많다(그래머2 = 새 단어 0).
- `R4/work/r4_work_b1`(레벨 4): vous·조건법·si 절 ✓.
- R0 짧은 회화 편 없음.

### 사용자에게 물은 것 — ✔ 2026-11-08 답: 어휘는 "절벽 단어 참고, 절대적이진 않음", 나머지 셋은 추천안. 문법 요소 배치는 `docs/GRAMMAR_LEVELS_FR.md`
- B3/A1 어휘 상한: R1 tier 44 레마는 거의 기능어라 회화가 안 된다 → 레벨 1 어휘 상한을 R3 146 + 코어 40(또는 R4 491)로.
- A3 단수 우선: 구어 `on`(= 우리)은 3인칭 단수 활용이라 레벨 1부터 허용(nous 활용만 그래머2).
- A9 성별판: 바뀌는 턴이 적어 본문은 바뀌는 턴만 `fr_f`, 음성은 규칙대로 모든 턴 두 판.
- A6: R5 새 레마 약 1,509 > 1,000 → B(1,000 넘는 언어) 검토 대상.
